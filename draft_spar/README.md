# Draft SPAR

How much value a draft slot returns, measured in Standings Points Above
Replacement over a player's approximate prime years.

## Data

The data used here requires a subscription to
[Evolving Hockey](https://evolving-hockey.com/). To run
`scripts/draft_spar.R` you need two exports covering the 2007-08 through
2019-20 seasons:

1. Standard skater data, including the additional info columns
2. SPAR skater data

Point the read paths in the script at wherever you save them, install the
dependencies listed in the repository README, and it should run.
